# מאמנים — תוכנית מימוש

> אפיון: [docs/superpowers/specs/2026-09-04-coaches-design.md](../specs/2026-09-04-coaches-design.md)

**מטרה:** אחרי הדראפט מוגרל מאמן אמיתי; הסגנון שנכתב עליו משנה את אופי העונה בלי לשנות את הסיכוי לזכות בה.

**ארכיטקטורה:** `js/coach.js` מחזיק את כל ההיגיון (טבלת ארכיטיפים, דרגה, הגרלה, חישוב המכפילים, שלושת המסכים). game.js מקבל ארבע נקודות מגע קטנות ושמורות ב-`if (typeof ... === 'function')`, בדיוק כמו הכימיה, התגיות והגאונטלט. sim-engine.js מקבל פרמטר `mods` אופציונלי שברירת המחדל שלו ריקה, כך שכל קריאה קיימת רצה בדיוק כפי שרצה.

**כלים:** JS ווניל, בלי בנייה. הרסות ב-Node תחת `scripts/sim/`.
